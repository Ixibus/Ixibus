# Ixibus ✨

Hello Hello 🙂

**Développeur full stack** récemment diplomé du RNCP 6 **Concepteur et Développeur d'Application**. 

Actuellement **Encadrant à l'ADA Tech School**, j'enseigne les technologies et logiciels relevant des compétences de base full stack web (HTML, CSS, JavaScript, l'algorithme, terminal, Bash, Git, Github et VScode).

J'entame deux ans d'études afin d'obtenir le **RNCP 7 d'Expert en Architecture et Développement Logiciel**. Je suis donc ouvert à toutes opprotunités pour une **alternance de deux ans** en tant que développeur full stack.

Mes stacks techniques de prédilections sont **TypeScript, React, Java / Spring-Boot, PostgreSQL, Supabase et Docker**. Je suis particulièrement à l'aise sur le dévelopepement d'application engageant les **problématiques de logiques métiers** de gestion de rôles, le système d'inscription par la création de compte (flow Onboarding), la connexion à un profil personnalisé, le routage de pages, la gestion des endpoints et les logiques CRUD.

J'ambitionne d'être **expert en architecture et développement logiciel spécialisé dans le DevOps** 🎯✨
